# Animated Upload Button 📤 | 30-Second Web Lab #15

A lightweight, interactive file upload button with dynamic loading progress and success feedback built with pure HTML, CSS, and Vanilla JavaScript.

## 🚀 Features

- ⚡ **Zero Dependencies:** Pure Vanilla JavaScript (no frameworks).
- 🎨 **Modern Dark UI:** Clean dark theme with smooth color transitions.
- 📦 **Boxicons CDN:** Lightweight vector icons.
- 🔄 **Dynamic State Feedback:** Smooth progress fill and icon transformation (`Upload` ➔ `Loading` ➔ `Success`).
